# Akinin-System-Module

## Назначение модуля
Модуль аутентификации и управления пользователями для гибридной интеллектуальной системы.

## Стек технологий
- Backend: Python 3.11, FastAPI
- Database: PostgreSQL
- Testing: Pytest, Gherkin
- CI/CD: GitHub Actions

## Основные функции
1. JWT-аутентификация пользователей
2. Управление ролями и доступом
3. Логирование действий

## API Endpoints
- POST /auth/login - получение токена
- POST /auth/register - регистрация пользователя
