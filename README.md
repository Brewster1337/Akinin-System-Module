# Akinin-System-Module

## Назначение модуля
Модуль векторизации текста для гибридной интеллектуальной системы. Преобразует естественный язык в векторные представления (embeddings) для LLM-агентов.

## Стек технологий
- **Backend**: Python 3.11, FastAPI
- **Векторизация**: sentence-transformers (all-MiniLM-L6-v2)
- **База векторов**: FAISS / Qdrant
- **Тестирование**: Pytest, Gherkin
- **CI/CD**: GitHub Actions

## Основные функции
1. Преобразование текста в векторные представления (embedding)
2. Пакетная векторизация нескольких текстов
3. Вычисление косинусного сходства между векторами
4. Кэширование векторов для повторного использования

## API Endpoints
- `POST /vectorize` — векторизация одного текста
- `POST /vectorize/batch` — массовая векторизация
- `POST /similarity` — сравнение двух текстов
- `GET /health` — проверка работоспособности

## Модель векторизации
- **Используемая модель**: all-MiniLM-L6-v2
- **Размерность вектора**: 384
- **Поддерживаемые языки**: русский, английский
